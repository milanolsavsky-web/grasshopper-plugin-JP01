# Documentation

Start here if you are new to Grasshopper plugin development.

## Reading order

If you have never built a Grasshopper plugin before, read the pages in this order:

1. **[Software requirements](software-requirements.md)** - what to install and how
2. **[Setting up Rhino](setting-up-rhino.md)** - where to put your plugin so Grasshopper finds it
3. **[C# basics](csharp-basics.md)** - the minimum C# you need to write components
4. **[OOP basics](oop-basics.md)** - just enough object-oriented programming to understand the plugin structure
5. **[Plugin structure](plugin-structure.md)** - what each file does and how to add new components
6. **[VS Code tasks and debugging](vscode-tasks-and-debugging.md)** - build tasks, breakpoints, and step-by-step debugging
7. **[Git basics](git-basics.md)** - tracking your changes and collaborating
8. **[Help and resources](resources-and-help.md)** - where to find answers when you get stuck
