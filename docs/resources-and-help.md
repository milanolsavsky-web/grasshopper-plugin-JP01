## When you are stuck

1. **Read the error message.** C# error messages are usually specific about what went wrong and where.
2. **Search the McNeel forum.** Someone has likely had the same problem.
3. **Search with the exact error message.** Copy the error text and search for it online.
4. **Check the API docs.** If a method does not work as expected, look it up in the RhinoCommon or Grasshopper API reference.
5. **Ask on the forum.** Include: what you tried, what you expected, what happened instead, and the full error message.
